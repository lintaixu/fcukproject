# K線型態回測分析系統 (K-Line Pattern Backtesting System)

本專案是一個完整的 K 線型態識別與回測框架，具備自動抓取金融數據、辨識 20 種經典 K 線技術型態、執行交易回測以及產出績效分析報告的功能。

## 核心功能

1. **自動獲取數據**
   - 整合 `yfinance` API 自動下載台股/美股歷史資料。
   - 內建資料快取 (Cache) 機制，減少重複下載時間。
   - 包含開高低收 (OHLCV) 數據清理與異常值處理。

2. **強大的型態辨識引擎**
   - 支援辨識 **20 種經典 K 線型態**：
     - **單 K 型態**：錘子線、上吊線、倒錘線、十字線。
     - **雙 K 型態**：看漲/看跌吞沒、看漲/看跌孕線、穿刺線、烏雲蓋頂。
     - **三 K 型態**：晨星、晚星、三隻烏鴉、三個白兵。
     - **高級與組合型態**：三重頂、三重底、牛/熊旗形、看漲/看跌楔形。

3. **回測引擎**
   - 自動將識別出的型態轉化為買賣信號進行模擬交易。
   - 支援自定義初始資金、交易手續費、滑點 (Slippage)。
   - 內建停損 (Stop Loss) 與停利 (Take Profit) 參數調整。

4. **績效分析與可視化報告**
   - 透過勝率、盈虧比、夏普比率、最大回撤等指標對各型態進行**綜合評分與排名**。
   - 自動產出三種格式的報告：
     - `analysis_report.html`：排版精美的互動式 HTML 報表。
     - `patterns_stats.csv`：供 Excel 開啟的統計數據表。
     - `backtest_results.json`：詳細的交易紀錄資料。

## 系統架構

- `main.py`：主程式入口，負責串接資料獲取、型態辨識、回測與報告生成。
- `data_fetcher.py`：負責向 Yahoo Finance 獲取資料並進行處理。
- `pattern_recognizer.py`：K 線型態辨識引擎，包含所有型態的邏輯實作。
- `backtester.py`：負責模擬交易與計算損益績效的引擎。
- `analyzer.py`：分析回測結果，進行評分並匯出 HTML/CSV/JSON 報告。
- `config.py`：系統的參數配置檔 (包含回測參數、股票清單、日期區間等)。

## 快速開始

### 1. 安裝依賴套件

請確保你的環境已經安裝了 `requirements.txt` 中列出的套件：

```bash
pip install -r requirements.txt
```

*(主要依賴包含 `pandas`, `numpy`, `yfinance` 等)*

### 2. 執行回測程式

在終端機中執行以下指令即可開始整個分析流程：

```bash
python3 main.py
```

### 3. 查看結果

執行完成後，系統會在專案根目錄下產出報告，你可以直接使用瀏覽器開啟 `analysis_report.html` 來看各個型態的回測勝率與排名。

## 自定義設定

你可以打開 `config.py` 來修改回測的行為：

- 修改 **股票清單** (`STOCK_SYMBOLS`) 來測試你感興趣的標的。
- 修改 **回測區間** (`ANALYSIS_PERIOD`) 來拉長或縮短測試時間。
- 調整 **停損/停利比例** (`BACKTEST_CONFIG`) 或是 **滑點** 以符合更真實的交易情境。
