# Chart-GCN 操作文檔(簡易版)

> 目的:讓任何人能在這台機器(或新環境)重現本專案的實驗。
> 更新:2026-07-27。

## 1. 環境

- Python ≥ 3.10
- 安裝依賴:`pip install -r requirements.txt`
- **一律從 repo 根目錄執行指令**(價格快取 `./cache/` 是相對路徑)

## 2. 三支執行器(只用這三支,其他舊腳本已移除)

### 2.1 標準實驗:`test/run_paper_repro.py`

```bash
# 標準乾淨協定(date 批次 + raw 特徵 + 網格最佳參數)
python test/run_paper_repro.py --raw-features --batch-mode date \
    --window 140 --m-pips 80 --N 10 --g 4 --seed 42 --tag 我的實驗名
```

每次執行自動:訓練 → 測試 → 回測 → JSON 存 `experiments_paper/` → 摘要 append 到 `實驗記錄_論文對齊.md`。

**常用參數:**

| 參數 | 說明 |
|---|---|
| `--tickers` | 股票池:`tw50`(預設)/`tw100`/`tw200`/`tw500`(554 檔)/`elec_all`(全電子 455)/`semi`(半導體 96)/`elec_comp`(零組件 104)/`fin_all`(金融 32)/`sse50`(上證 50) |
| `--n-stocks N` | 取池子前 N 檔(0 = 全部);規模實驗就是 `--tickers tw500 --n-stocks 100/150/...` |
| `--batch-mode` | **一律用 `date`**(同日一批,無洩漏);`paper` 是舊協定,有未來洩漏,只用於對照 |
| `--raw-features` | **一律要加**(z-score 會使模型塌縮) |
| `--seed` | 隨機種子;多 seed 驗證用 42/43/44 |
| `--workers` | **一律用 1**(預設)——workers>1 會因分頁檔不足全部崩潰(WinError 1455) |

### 2.2 網格搜尋:`test/grid_search_paper.py`

```bash
python test/grid_search_paper.py --batch-mode date
```

論文 4.3 範圍兩階段搜尋(w×m 16 組 → N×g 15 組),以 val macro-F1 選參,結果自動記錄。

### 2.3 XGBoost 對照:`test/run_xgb_baseline.py`

```bash
python test/run_xgb_baseline.py --market tw    # 台股;--market cn 為上證
```

讀同一份 dataset 快取(同測試集/同標籤),只換模型。

## 3. 快取機制(為什麼第二次跑很快)

- **價格快取**:`cache/*.parquet`——yfinance 下載一次後不再重抓。
- **Dataset 快取**:`experiments_paper/dscache/*.npz`——同一組(股票池, 期間, w/m/N/g/stride)參數只建構一次;
  第一次建構 50 檔約 6 分鐘、500 檔約 1 小時,之後同參數重跑秒載。
- 兩種快取都**不進 git**(.gitignore 已排除)。

## 4. 讀結果

- 每筆實驗:`experiments_paper/EXP-<時間>_<tag>.json`(指標)+ `_backtest.png`(回測圖)+ `_model.pt`(權重)。
- 人讀的彙整:`實驗記錄_論文對齊.md`(自動 append,含歷次審查結論與總表)。
- **指標判讀**:類別不平衡下 Acc 會獎勵「全押跌」(2024 地板約 54%),要看 **F1 macro**;
  全押單邊的數學下限 F1m ≈ 35%、均衡亂猜 ≈ 50%。

## 5. 注意事項(踩過的坑)

1. `--workers` 只能 1(分頁檔限制)。
2. 長時間實驗用獨立程序跑、機器不能睡眠。
3. yfinance 的 `end` 是右開區間(少最後一天)、volume=0 假 bar 未濾——已知資料層問題,見實驗記錄第三節。
4. 舊的 `paper` 批次模式有未來洩漏,任何新數字都不要用它。
5. 下市股票會被自動略過,實際檔數以執行時 `[DATA] N 檔股票` 為準。
